## 本地开发

无需 npm 构建。开发版本在本目录运行 `node tools/serve.cjs`，预览端口为 8771。使用本地 Three.js 0.180.0，许可见 `js/vendor/three/LICENSE`。

`tools/`、`validation/` 和本地交付记录仅保留在开发目录，不发布到 GitHub Pages。开发验证包含桌面与触屏模拟；实体手机传感器和所有真机浏览器未逐一测试。

照片场景是单张照片的视觉重建；模型首次加载时间与帧率受网络及硬件影响。作品集界面与原始 PDF/图片内容分开维护。
